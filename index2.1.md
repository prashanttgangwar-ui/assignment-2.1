1. Aim

To create a basic HTML webpage using a title, headings, paragraphs, and HTML comments.

2. Software Required

Visual Studio Code

Google Chrome or any web browser

3. HTML Code

Create a file named index.html and write the following code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>

    <!-- Main heading of the webpage -->
    <h1>Welcome to My First Webpage</h1>

    <!-- Introduction section -->
    <h2>About Me</h2>
    <p>My name is Shubham Yadav. I am a B.Tech CSE student.</p>

    <!-- Education section -->
    <h2>My Education</h2>
    <p>I am learning computer science, programming, and web development.</p>

    <!-- My goals section -->
    <h2>My Goals</h2>
    <p>My goal is to improve my coding skills and become a successful software developer.</p>

    <!-- End of webpage content -->

</body>
</html>

4. Explanation

<!DOCTYPE html> declares that the document uses HTML5.

<html> is the root element of the webpage.

<head> contains information about the webpage.

<title> sets the browser tab title to "My First Webpage".

<body> contains the visible content of the webpage.

<h1> defines the main heading.

<h2> defines the subheadings.

<p> is used to write paragraphs.

<!-- --> is used to add comments that are not displayed on the webpage.

Proper indentation makes the code easy to read and understand.

5. Output

When the HTML file is opened in a browser, the webpage displays:

Welcome to My First Webpage

About Me

My name is Shubham Yadav. I am a B.Tech CSE student.

My Education

I am learning computer science, programming, and web development.

My Goals

My goal is to improve my coding skills and become a successful software developer.

The browser tab title will be My First Webpage.

6. Procedure to Run the Program

Open Visual Studio Code.

Create a new file named index.html.

Copy and paste the HTML code into the file.

Save the file using Ctrl + S.

Open the saved file in Google Chrome or another web browser.

Check that the title, main heading, subheadings, and paragraphs appear correctly.

Take a screenshot of the webpage for submission.

7. Result

Successfully created and displayed a basic HTML webpage using HTML5 elements, a page title, one main heading, three subheadings, paragraphs, comments, and proper indentation.
